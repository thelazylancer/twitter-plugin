X Viral Monitor

在推文起爆前，先一步看到它。X Viral Monitor 为时间线添加流速徽章和热点悬浮面板，帮助创作者发现高流量内容，及时参与讨论，获取更多曝光。

从 GitHub 加载这个 fork

没有商店版本。打开 chrome://extensions，开启开发者模式，加载仓库根目录或构建出的 dist/。

推荐 Chrome / Edge 扩展

把 AI 回复、评论过滤、流速徽章、热点榜单和长图阅读直接加到 X 时间线里。

核心能力

流速徽章

直接在推文旁显示 views/hour。看到 🚀 小火箭时，说明这条推文正在起爆，值得重点关注。

热点悬浮面板

自动整理当前页面的高流速推文，不用反复刷时间线，也能抓住正在升温的话题。

X 创作者增长辅助

更早发现高流量内容，在合适的推文下留下有观点、有信息量的评论，让账号进入更多活跃讨论。

长图与内容增强

长图阅读、图片增强、评论过滤和 AI 回复辅助，减少刷 X 和参与讨论时的阻力。

Pro 功能

这个 fork 不销售 Pro，也没有 License 服务。community-dev 构建会把流速过滤等上游 Pro 能力全部打开。

全部功能直接可用

流速过滤、分范围阈值等上游 Pro 能力，在本地构建里默认解锁，不需要激活。

需要和上游一致的闸门行为时，用 npm run build:dist 构建 store 渠道；这个 fork 不上架商店。

隐私边界
